# Pietro Dardano — Personal Academic Website

Personal academic website representing **Pietro Dardano**, PhD Candidate in AI & Robotics at BMW AI Robotics & TU Eindhoven.

🌐 **Live site**: [https://pietrodardano.github.io/](https://pietrodardano.github.io/)

---

## Architecture & Philosophy

Built with a **YAGNI (You Aren't Gonna Need It)** philosophy:
- **Zero build dependencies**: Pure Vanilla HTML5, CSS3, and JavaScript.
- **Fast & Minimal**: Zero node_modules, zero external framework overhead, instantaneous page loading.
- **Modernist Scientific Grid**: Clean squared-ish aesthetic, high-contrast typography, native Dark / Light mode toggle.
- **Centralized Data**: All news, publications, projects, and bio details live cleanly in `site-data.js`.
